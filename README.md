# Data Analytics Internship - Task 2

## Exploratory Data Analysis and Business Intelligence

This project is Task 2 of my Data Analytics Internship. It uses a cleaned e-commerce dataset to identify trends, answer business questions using SQL, and present insights through a static sales dashboard.

## Objectives

- Perform exploratory data analysis
- Analyze business questions with SQL
- Identify revenue trends and customer patterns
- Create a static e-commerce sales dashboard

## Dataset Summary

- Total orders: 1,499
- Total revenue: INR 5,845,247.70
- Average order value: INR 3,899.43
- Return rate: 15.08%

## Key Insights

- Smart Watch is the top product by revenue.
- Electronics is the top revenue-generating category.
- The South region has the highest revenue.
- Paid Search is the best-performing acquisition channel.
- Fashion has the highest return rate.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- SQLite
- VS Code
